**README**

This repository holds an trained model for recognizing hand-written numbers which uses MNIST as training/testing dataset, Pytorch as framework and is written in Python.

Source codes are provided in two version: original and GPT-annotated (annotation is in *Chinese*) with no difference in functionality.

This project is only for exercise purpose and is not gauranteed flawless. Please kindly use it as reference only. But I guess nobody will be interested :)
